I build things with software and, when the solder holds, hardware. This site is a lab
notebook: half-finished experiments, notes to my future self, and the occasional
write-up that reached a conclusion.

Everything here is written in Markdown, built with Hugo, and served from GitHub Pages.
Diagrams are `pikchr` and `gnuplot` code fences, rendered to SVG at build time.
